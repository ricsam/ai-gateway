---
title: "LLM Proxy"
description: "A self-hosted, OpenAI-compatible gateway to AWS Bedrock with credits, analytics, and runtime administration."
---

LLM Proxy gives teams a controlled path to AWS Bedrock. Applications use a familiar OpenAI-compatible API while operators manage model access, pricing, users, groups, credentials, branding, and audit history from one deployment.

<Card title="Send your first request" icon="rocket" href="/docs/quickstart" cta="Open the quickstart" arrow="true">
  Create an inference key, discover an enabled model, and call Chat Completions.
</Card>

<Columns cols={2}>
  <Card title="OpenAI-compatible" icon="message-square">
    Use `/v1/chat/completions` with streaming, tools, image data URIs, and reasoning controls.
  </Card>
  <Card title="Metered access" icon="coins">
    Apply per-user balances and monthly allocations with model-specific token and cache pricing.
  </Card>
  <Card title="Runtime control plane" icon="sliders-horizontal">
    Change users, groups, models, AWS credentials, auth providers, and branding without rebuilding.
  </Card>
  <Card title="Self-hosted" icon="server">
    Run with Docker Compose or deploy to Kubernetes with the included Helm chart.
  </Card>
</Columns>

AI Gateway runs as deployment/{{ include "ai-gateway.fullname" . }} in namespace {{ .Release.Namespace }}, serving {{ .Values.config.baseUrl }}.

Manage it with aigctl inside the pod (users, groups, keys, credits, settings, AWS, login providers, audit, usage):
  kubectl -n {{ .Release.Namespace }} exec -it deploy/{{ include "ai-gateway.fullname" . }} -- aigctl --help

On a new installation, create the first administrator right away; this closes the /setup page for good:
  kubectl -n {{ .Release.Namespace }} exec -it deploy/{{ include "ai-gateway.fullname" . }} -- aigctl setup init --username admin --email admin@example.com

Anyone allowed to exec into these pods can administer the gateway: aigctl uses the pod's own database access.
